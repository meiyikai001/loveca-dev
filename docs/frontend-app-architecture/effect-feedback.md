# 通用卡效反馈：第一批

## 当前范围

共享 `GameBoard` 默认挂载 `EffectFeedbackLayer`。普通本地与联机玩家使用同一套展示；当前不在只读回放、观战中播放。单项反馈最长 1250ms，同一公开事件的多个目标并行，批量事件最多展示最近 8 项，新事件立即响应；不会增加命令屏障、延迟卡效、截获鼠标或暂停选择窗口。普通动态下 HEART／BLADE 增益数值在 250ms 开始浮现、约 469ms 全亮，915ms 开始淡出、1200ms 消失；其他数值、费用及状态类中性提示在 240ms 全亮，1056ms 开始淡出、1200ms 消失。减少动态仅保留约 220ms 的淡入淡出提示。

- 实际数值效果应用后，来源卡出现短暂柔光，目标立即响应；START 待处理窗口、能量支付和活跃／待机变化仅保留原状态动作及数值提示，不播放增益扫光，不绘制跨卡连线。HEART、BLADE 恢复原柔光外晕、卡沿亮边和内层光泽；混合种类、多色和增减变化仍逐项保留，不由首项颜色或单一 BLADE 分支覆盖其他结果。准确增量由对应图标和数字表达，柔光不用于表示增量数量。分数及需求沿用较弱的局部反馈与数值提示，不另加目标卡回弹。
- 成员 HEART、BLADE，玩家 LIVE 区加心／BLADE／加分，单张 LIVE 加分及必要 HEART 减量。
- 卡效 wrapper 派发的成员活跃／待机变化；现有能量的活跃数量变化。
- 抽牌、弃牌、回收、普通移牌和卡牌方向动画继续由原有 `BattleAnimationLayer` 处理，其中休息室到手牌的回收复用原移动卡牌，增加起点亮边、移动卡面扫光，不绘制回收连线，飞行逐帧跟随真实手牌的位置、缩放与扇形角度，避免窗口收起后的旧落点造成跳动；飞行 400ms，短暂起飞后快速移动，末段减速贴合手牌（减少动态时为 120ms 区域提示），公开展示停留时间保持不变。移动素材仍由原有正面／背面可见性判断提供。无目标、跳过和非法命令不会凭空显示增益或回收成功。

不覆盖原始费用变化、判心授予／改色、规则限制文案、声援翻牌和 LIVE 聚光灯。不为每张卡添加展示配置，也不从中文卡文推测目标。只写入旧兼容字段、没有 canonical modifier 的历史效果不获得新的数值反馈；不得为了动画重写这些规则路径。

## 当前柔光表现

本轮仅将 HEART／BLADE 的纹理光点、尾迹和光束改回柔光表现，保留本轮已完成的事件内分组、混合结果展示、目标跟随、同目标替换和生命周期清理。柔光通过卡片本地 portal 随真实卡牌旋转、缩放和移动，图标与数值保持屏幕直立；实际生效后才发光。

纹理粒子方案移出运行时代码，仅在仓库外 `../animation-prototypes/effect-feedback-20261003/` 保留试验。当前卡效反馈不再引入或预加载 `Particle02.png`、`Line01.png`、`rainnaka.png`，也不等待贴图加载或解码；数值提示和 1250ms 生命周期不依赖这些素材。该调整不涉及已认可的登场落场纹理。

## 来源与边界

`GameSession.buildDerivedPublicEvents` 调用 `src/online/effect-feedback.ts`，根据已完成的权威状态转换派生 `EffectFeedback` 公开事件。事件只有公开对象 ID、区域、变化类别、颜色与实际增量，没有私密卡号或文本。

数值沿用领域有效 HEART/BLADE/需求查询及 `collectLiveModifiers`，仅使用转换前后均对双方公开的 modifier（单纯公开／隐藏依赖不伪装成获得／失去数值）；同一来源、同一 ability 的连续授予合并目标，重复授予保留次数，BLADE/需求以有效值钳制后的差计算。持续条件变化、移除及能量变化使用较弱的 UPDATE，不虚构来源连线。来源在前后任一状态中公开才能携带对象 ID，前端还要确认其当前为正面且可定位。

START 表示出现待处理能力；APPLIED 表示已发生的实际 modifier／方向变化，**不表示整条能力成功**。例如自身待机费用与稍后选心分别发生，后续取消或无目标不会撤销已发生的费用反馈。普通移牌的因果不可靠时沿用移牌动画，不从“最后一个 activeEffect”猜测来源。

客户端 `effectFeedback.ts` 管理消费游标与去重；`effectFeedbackPresentation.ts` 管理事件内分类、目标有效性和展示替换。首次挂载以当前 view.seq 建立水位，即使日志随后补齐也不补播历史；切换对局／座位、回退、恢复 presentationEpoch、只读与禁用状态均重置。每帧校验公开正面目标仍在原区域且 DOM 身份未变。光效通过 portal 挂在真实卡牌内，随卡牌方向及变换；文字保持屏幕正向并逐帧跟随目标矩形。区域效果挂在己方／对方统一公开区域锚点。目标离场、转为隐藏、节点消失或替换时立即清理，不追进手牌或落在替代卡上；拖拽隐藏原卡时，任一祖先的 `opacity: 0` 同样会触发原卡反馈清理。登场演出等待期间消费但不播放卡效反馈；效果仍服从既有登场同步机制。

公开日志列表和未读数排除此展示事件；记录协议仍认识它。第一批公开事件接入的发布需要同步更新共享/API 与前端，无数据库迁移或环境变量。本轮柔光表现和混合反馈修复不修改公开协议。此反馈与现有“登场动画”开关是不同范围，本批未增加新的玩家／管理员配置。

同一事件内按种类、颜色和增减方向保留各项变化，混合 HEART／BLADE 不只显示第一项。同一目标的新事件立即替换旧装饰及提示，不排队、不跨事件相加，不凭来源和时间推断能力归属；不同目标可以并行。使用单个活动帧循环，最后一项结束、切换对局、禁用或卸载后停止。

`tests/unit/effect-feedback.test.ts`：实际增量、多目标、重复授予、到期、隐藏来源／条件、成员状态因果、游标恢复／晚到日志、目标离场、日志过滤。

`tests/integration/effect-feedback.test.ts` 与 `tests/helpers/effect-feedback-fixture.ts`：真实能力命令完成加心、待机、群体 BLADE、分数、需求、自身待机费用选心、弃牌回收和支付费用后无目标；非法选择没有事件。初始夹具与后续命令分开，不伪造完成后的动画状态。

本批一次性验收页在仓库外 `../animation-prototypes/effect-feedback-20261003/`，复用上述夹具及真实 `GameBoard`。README 记录启动与验收清单；第一轮客户端表现调整截图在仓库 `output/playwright/vfx-*-20261004.png`，更早截图保存在该验收页目录的 `evidence/`。页面不作为产品入口发布。

第一轮客户端表现调整完成 8 文件 77 项相关测试、客户端类型检查及生产构建（仍有既有大 chunk 提示）。真实桌面检查加心、群体 BLADE、费用无增益光、横置卡与浅色桌面；390px 窄屏检查目标提示边界、落场和跳过清理。混合颜色／种类与同目标替换由单元测试覆盖，未实测所有混合情况的真实卡效浏览器场景。该轮减少动态使用隔离页媒体查询替身检查，未使用系统设置实测。

## 当前限制与后续

已认可的登场落场保留本轮平面扩散环、接触阴影和邻卡响应。卡面已有随倾角变化的轻微反光／暗化尝试，进一步材质升级（C）继续延后；400ms 回收飞牌及其可见性边界保持不变。本轮恢复 HEART／BLADE 柔光，同时保留混合变化、目标跟随、新事件替换及不可见目标清理；不修改公开协议或卡效规则。真实双客户端网络、系统减少动态设置及低端设备性能尚未实测。移动目标会结束原区域反馈，不把尚未播完的装饰带入新区域。

LIVE 聚光试作仍搁置；声援翻牌、音效、特殊歌曲演出不在本轮范围。
