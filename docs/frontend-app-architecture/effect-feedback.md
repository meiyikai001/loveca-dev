# 通用卡效反馈：第一批

## 当前范围

共享 `GameBoard` 默认挂载 `EffectFeedbackLayer`。普通本地与联机玩家使用同一套展示；当前不在只读回放、观战中播放。单项反馈最长 1250ms，同一能力的多个目标并行，批量事件最多展示最近 8 项，间隔 100ms；不会增加命令屏障、延迟卡效、截获鼠标或暂停选择窗口。减少动态时仅保留约 220ms 的淡入淡出提示。

- 实际数值效果应用时来源卡亮起，目标约 150ms 后响应；START 待处理窗口、能量支付和活跃／待机变化仅保留原状态动作及数值提示，不播放增益扫光，不绘制跨卡连线。正向 HEART 使用对应颜色柔光与上散光点，BLADE 使用斜向卡面扫光与短光芒；图标和实际增量浮现，目标卡轻微回弹。其他反馈保留局部扫光与数值提示。
- 成员 HEART、BLADE，玩家 LIVE 区加心／BLADE／加分，单张 LIVE 加分及必要 HEART 减量。
- 卡效 wrapper 派发的成员活跃／待机变化；现有能量的活跃数量变化。
- 抽牌、弃牌、回收、普通移牌和卡牌方向动画继续由原有 `BattleAnimationLayer` 处理，其中休息室到手牌的回收复用原移动卡牌，增加起点亮边、移动卡面扫光，不绘制回收连线，飞行逐帧跟随真实手牌的位置、缩放与扇形角度，避免窗口收起后的旧落点造成跳动；飞行 400ms，短暂起飞后快速移动，末段减速贴合手牌（减少动态时为 120ms 区域提示），公开展示停留时间保持不变。移动素材仍由原有正面／背面可见性判断提供。无目标、跳过和非法命令不会凭空显示增益或回收成功。

不覆盖原始费用变化、判心授予／改色、规则限制文案、声援翻牌和 LIVE 聚光灯。不为每张卡添加展示配置，也不从中文卡文推测目标。只写入旧兼容字段、没有 canonical modifier 的历史效果不获得新的数值反馈；不得为了动画重写这些规则路径。

## 来源与边界

`GameSession.buildDerivedPublicEvents` 调用 `src/online/effect-feedback.ts`，根据已完成的权威状态转换派生 `EffectFeedback` 公开事件。事件只有公开对象 ID、区域、变化类别、颜色与实际增量，没有私密卡号或文本。

数值沿用领域有效 HEART/BLADE/需求查询及 `collectLiveModifiers`，仅使用转换前后均对双方公开的 modifier（单纯公开／隐藏依赖不伪装成获得／失去数值）；同一来源、同一 ability 的连续授予合并目标，重复授予保留次数，BLADE/需求以有效值钳制后的差计算。持续条件变化、移除及能量变化使用较弱的 UPDATE，不虚构来源连线。来源在前后任一状态中公开才能携带对象 ID，前端还要确认其当前为正面且可定位。

START 表示出现待处理能力；APPLIED 表示已发生的实际 modifier／方向变化，**不表示整条能力成功**。例如自身待机费用与稍后选心分别发生，后续取消或无目标不会撤销已发生的费用反馈。普通移牌的因果不可靠时沿用移牌动画，不从“最后一个 activeEffect”猜测来源。

客户端 `effectFeedback.ts` 管理消费游标、去重与公开锚点定位。首次挂载以当前 view.seq 建立水位，即使日志随后补齐也不补播历史；切换对局／座位、回退、恢复 presentationEpoch、只读与禁用状态均重置。延迟播放前重新查询当前公开目标，目标离开原区域后不得落在替代卡上。登场演出等待期间消费但不播放卡效反馈；效果仍服从既有登场同步机制。

公开日志列表和未读数排除此展示事件；记录协议仍认识它。发布需要同步更新共享/API 与前端，无数据库迁移、环境变量或额外素材。此反馈与现有“登场动画”开关是不同范围，本批未增加新的玩家／管理员配置。

## 验收

`tests/unit/effect-feedback.test.ts`：实际增量、多目标、重复授予、到期、隐藏来源／条件、成员状态因果、游标恢复／晚到日志、目标离场、日志过滤。

`tests/integration/effect-feedback.test.ts` 与 `tests/helpers/effect-feedback-fixture.ts`：真实能力命令完成加心、待机、群体 BLADE、分数、需求、自身待机费用选心、弃牌回收和支付费用后无目标；非法选择没有事件。初始夹具与后续命令分开，不伪造完成后的动画状态。

本批一次性验收页在仓库外 `../animation-prototypes/effect-feedback-20261003/`，复用上述夹具及真实 `GameBoard`。README 记录启动与验收清单，截图在该目录 evidence/。页面不作为产品入口发布。


## 首版限制与后续

未完成真实双客户端网络视觉验收。播放中的增益浮层使用开始时的矩形，玩家在约 1.25 秒内再次移动目标时可能短暂留下旧位置反馈；同一目标快速连续受益时，提示可能重叠。现有去重、延迟播放前目标重验与对局切换清理不等于解决这两个边界，后续应按目标取消或合并展示。

下一阶段为 LIVE 通用演出：先做开始时的舞台聚光，再做成功／失败与得分反馈。逐张声援翻牌、指定歌曲专属演出另行讨论，不作为本批完成内容。
